## 버전 관리 규칙

- 파일명·폴더명에 `v<주>.<부>_<YYYY-MM-DD>`를 붙입니다.
  - **주 버전**: 구조 변경, 제품 방향 변경, 지식베이스 섹션 추가·삭제.
  - **부 버전**: 사실 정정, 출처 추가, 문구 수정.
- 바뀐 내용은 `CHANGELOG.md` 맨 위에 추가합니다.
- `MANIFEST.sha256`으로 파일이 바뀌었는지 확인할 수 있습니다 (`sha256sum -c MANIFEST.sha256`).
- 이전 버전 zip은 지우지 않고 보관합니다.
