# WOW 선택 기준과 제품 MVP 결정 게이트

## 정성 스코어(각 0~5), 제품 확정 전에는 공란으로 둔다
- 반복 빈도: 분기 1회보다 주·월 단위 발생이 유리(기준은 대상 프로세스에 맞게)
- 기존 시간/비용: 자료 탐색·재작업·대기 등 순수 절감 가능 시간
- 한 화면에서 보여줄 WOW: 전후 차이가 즉시 관찰되는가?
- 기존 도구 대비 추가 가치: 고객이 이미 쓰는 시스템과 비교해 실제 차이가 있나?
- 진입 허들: 비밀유지/클라우드/계정·ERP 접근권/데이터 범위
- 구매 가능성: 지갑을 여는 Partner가 투자 수익을 이해하나?
- 기술 신뢰성: 거짓 경보와 중요한 오류 누락, 재현성 관리 가능성

## Gate 0 — 발견 검증
- 두 개 이상 규모의 법인에서 **같은 작업 사건**이 반복 보고됐는가?
- 최소 3명 이상이 최근 1개월의 실례와 소요시간을 제시했는가? 목표(검증된 수치 아님).
- 현재 활용 도구/매크로/벤더를 확인했는가?

## Gate 1 — 데모 검증
- 비식별/합성 실무형 파일로 핵심 행동이 실제 수행되는가?
- 자동 생성 항목마다 원본 출처가 있는가?
- 지적 항목을 감사인이 재현할 수 있는가?
- 안전하게 판단을 사용자에게 돌려주는가?

## Gate 2 — 실제 전후 비교
- 같은 사람·같은 난도의 과제를 랜덤 순서로 기존 방식/시제품에서 수행.
- 측정: `T_total=준비+도구작업+사람검토+오류수정+출력`.
- `시간 절감율 = (T_before - T_after) / T_before`.
- 반드시 **누락오류·오탐·클라우드 온보딩·보안 심사 비용** 별도 측정.
- 임의로 '75%'를 제품 결과로 말하지 않음.

## Gate 3 — 구매
- 파트너 또는 승인권자가 실제 파일럿 계약/유료 사용을 진행하겠는가?
- 보안심사를 통과할 설치 방식(웹/국내 리전/사내 설치/로컬)이 존재하는가?
- 법률·감사기준 전문가가 제품 표현과 핵심 흐름을 검토했는가?

## MVP 구축 우선순위 원칙
1. AI 채팅창보다 **버튼 하나로 해결되는 직접적 업무**.
2. `숫자·ID 대사`는 규칙·코드 우선, `문서 의미 추출`만 AI 보조.
3. AI 답에는 신뢰점수보다 **파일명, 시트, 셀/행, 기준 적용일, 확인 방법**.
4. 사건별 Before/After 30초 데모가 가능해야 한다.
5. 고객의 원본 파일/감사 의견을 자동 수정하지 않는다.
6. 결과의 책임은 감사인에게 있고, 제품은 판단자료를 구조화해 제시한다.
