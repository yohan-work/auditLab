# 경쟁사 배제 지도 — '이미 있는 기능'을 다시 팔지 않기

2026-10-21 공개 제품 설명 기준. 실제 계약·버전별 기능은 다를 수 있음.

| 기능 | 공식 확인된 경쟁 관찰 | 신규 SaaS로서 함정 | 독립 진입을 검증할 조건 |
|---|---|---|---|
| 감사 계획·위험평가 Agent | Fieldguide Field Planner, EY 플랫폼 | 정면경쟁, 방법론 유지비 | 특정 산업/서식의 검증 불가피한 예외 업무 |
| 원장 대사·증빙 검사 | Fieldguide Field Auditor, EY Helix/Document Intelligence | 기능 중복 | 고객사 ERP의 특수 포맷에서 확실한 추가 절감 |
| 감사조서 AI 리뷰 | Fieldguide Field Reviewer | 중복 | 기존 Excel 조서를 건드리지 않고 검증 가능 |
| PBC 요청/수령 | Fieldguide Request Management/Client Hub | 중복 | 회계법인이 아닌 회사 측에 실질 효용이 있는 구조 |
| AI 회계 기준 검색 | EYQ Assurance Knowledge, KPMG RAG 채용 | 중복 | 구체적 기준의 적용 버전 자동 식별/검증 증명 |
| 원장·조서 사이 변경파급 | 복수 플랫폼의 버전/연결 기능 존재 | **미개척이라고 주장 불가** | 외부 도구·매크로·분리 파일까지 영향 추적의 검증 가능한 사례 |
| 프로젝트 인수인계·Reviewer 질의 | 일부 감사 워크플로에서 제공 가능 | 상세 기능/고객 도입 모름 | '검토 코멘트 반복'이 실제로 남는 문제인지 고객 증언 |

출처: Fieldguide 공식 S11/S12; EY 감사 기술 S13; 삼정KPMG TFT·채용 S14/S15.

### 발견의 프레임
- 대형 법인의 전사 엔드투엔드 대체보다 **기존 Word·Excel·메일을 유지**하는 경량 도구.
- '법적으로 해야 하니까 산다'가 아니라 **반복 사용 빈도 × 고통 × 실측 시간 절감 × 예산·보안 통과**.
- 경쟁력이 생길 수 있는 구간은 특정 업무의 **첫 5분(입력 준비)**, **마지막 5분(재검토·승인 전)**, **도구 간 넘김(handoff)** 이다. 이것도 가설.
- 웹·Excel 플러그인 및 로컬 처리형은 도입 방식 차별화 가설. 웹 기반만 고집하지 않음.

### 금지 표현
- 'Fieldguide에는 이 기능이 없다' (공식 공개 자료로 부재 검증 불가)
- '한국 중소법인은 모두 Excel만 쓴다' (도입률 미확인)
- '리뷰 오류 100% 방지' (비현실적)
