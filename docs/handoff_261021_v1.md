## 1. 프로젝트 한 줄 요약

국내 **Big4가 아닌** 중소·중견 회계법인과 감사반에서 외부감사를 하는 회계사를 대상으로, 반복 업무를 줄이는 **유료 SaaS**를 만든다. 그 전에 회계사 업무·규칙을 **법적 근거가 있는 사실(팩트) 기반 지식베이스**로 먼저 쌓는다.

### 사용자(최요한)가 정한 조건

1. Big4는 자체 AI 조직이 있어 경쟁 대상에서 제외 (레드오션).
2. 실제 회계사가 "와, 이거 대박이다" 할 반복 업무 개선 또는 아직 시도되지 않은 아이디어가 목표.
3. 본인은 회계사 업무를 전혀 모름 → **지식베이스는 기획 자료가 아니라, 회계사가 어떻게 일하고 어떤 규칙을 따르는지에 대한 법적 근거 있는 사실만** 담는다. (조·항 단위 출처 필수)

### 하지 않을 것

- Big4 전사 감사 플랫폼 복제
- AI가 감사의견을 내거나 결론을 확정하는 기능
- 감사인 대신 회사 재무제표를 작성하는 기능 (외부감사법 제6조⑥ 위반 소지)
- 근거 없는 효과 수치 제시 (예: "75% 절감"). 효과는 파일럿 실측으로만.

## 4. 지식베이스 핵심 내용 (요약)

근거 등급: `[법률]` `[시행령·규정]` `[기준]` `[감독기관]` `[관행]` `[확인 필요]` GPT KB 표기와 대응: A_OFFICIAL ≈ 법률·시행령·기준 / C·H ≈ 관행 / U_UNVERIFIED ≈ 확인 필요

- **자격**: 시험 합격 = 자격(공인회계사법 제3조) → 1년 이상 실무수습 → 금융위 등록(제7조①). 외부감사는 1~2년 추가 수습 필요(금융위 2017).
- **감사인**: 상장사 감사인 등록 회계법인(39곳), 일반 회계법인, 감사반(외부감사법 제2조7호). 감사반은 상장사·대형비상장·금융회사 감사 불가.
- **규칙 체계**: 외부감사법·공인회계사법 → 시행령·금융위 규정 → 회계감사기준(제16조)·품질관리기준(제17조), 한공회 제정·금융위 승인 → 윤리기준 → 법인 내부 매뉴얼. **회계처리기준(K-IFRS 등)은 회사가 따르는 규칙**이고 감사기준과 다름.
- **2026 개정 품질관리기준서 1·2, 감사기준서 220** (KICPA 2026.8.6 공표, 원문 확인): 등록법인 2027.12.31, 그 외 법인·감사반 2029.12.31 기준으로 단계 적용.
- **프로세스 9단계**: 수임·독립성 → 계획·중요성 → 위험평가 → PBC → 통제 테스트 → 실증절차 → 리뷰 → 완료·보고 → 조서 마감·보존. 전수 검사가 아니라 위험 기반.
- **기한**: 회사 재무제표 제출 정기총회 6주 전(시행령 제8조), 감사보고서 제출 1주 전(시행령 제27조) → 최종 검증 약 5주.
- **금지·의무**: 대리작성 금지(제6조⑥, 3년/3천만원), 비밀엄수(제20조), 자료요구권(제21조①), 조서 8년 보존(제19조, 원문 대조 필요), 직무제한(공인회계사법 제21·33조).
- **제재**: 증선위 조치(제29조), 금융위 등록취소·직무정지, 형사(제42·44조), 민사(제31조, 감사인이 무과실 입증).

## 5. 아이디어 현황 (가설 단계)

- **1순위 가설**: 전자세금계산서 3방향 전수대사 엔진 (가칭 K-Tieout). 회사 원장 × 홈택스 전자세금계산서 목록 × 은행 거래내역을 전 거래 대사, 불일치·기간귀속 위험만 표시, 결과를 조서 형식으로 출력.
  - 근거: 법인은 규모 무관 전자세금계산서 의무(부가가치세법 제32조②).
  - 주의: 매출 세금계산서는 회사 발행 → 은행 입금과 묶어야 증거력. 도구는 장부를 고치지 않음.
- 2차 후보: 조회서 회신 대사(금융결제원·NICE 회신 → 원장), 국내 ERP 원장 정규화 + 분개 테스트, 외부감사 실시내용 자동 작성.
- GPT KB의 관점도 유효: **제품은 아직 미선정**, "사건(event) 단위 10분 이상 반복 마찰"을 인터뷰로 먼저 찾는다.
- 다음 시즌: 12월 결산 기말감사 1~3월 → **12월 안에 데모·파일럿 법인 확보** 필요.

## 8. 작업 원칙 (다음 세션에도 유지)

1. 지식베이스에는 **사실만**. 모든 문장에 근거 등급, 법령은 조·항·호와 시행일.
2. 법령 원문은 국가법령정보센터, 기준은 KICPA 원문으로 최종 대조.
3. 발표일 ≠ 시행일 ≠ 적용 보고기간. 셋을 구분해 기록.
4. "경쟁사에 이 기능이 없다", "중소법인은 모두 엑셀만 쓴다" 같은 미검증 단정 금지.
5. 효과 수치는 파일럿 실측(`(T_before - T_after) / T_before`)으로만.
6. 회계사가 최종 판단·조서·의견의 주체. 도구는 판단 자료를 구조화해 제시.
